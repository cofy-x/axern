# Axern v0.8.1

Axern v0.8.1 completes the released Python external-runner contract introduced in v0.8.0. Deploy matching control, gateway, node, CLI, Proto, chart, and SDK builds.

## Public SDK Contract

- Python `AxernClient.create_run()`, `AsyncAxernClient.create_run()`, `Sandbox`, and `AsyncSandbox` accept `image_mounts`, `secret_env`, and `secret_files`.
- `ImageMount`, `SecretEnvVar`, and `SecretFile` convert through one shared wire path, so synchronous, asynchronous, and Sandbox APIs preserve identical optional, key, mode, and target semantics.
- Image mounts are always read-only. The unused public `readonly` boolean was removed instead of accepting a writable request that the platform ignored.
- Secret references are resolved within the owning Run Namespace. Plaintext is never accepted by the public Run API or returned in Run metadata. Secret-file modes are read-only, and both control and node reject protected runtime or critical system targets.
- Every inference or verification Run declares its own mounts and Secret projections. Environments and earlier Runs do not implicitly pass them on.
- Public `TunnelConnector` now inherits gateway mTLS transport from an `AxernClient`, bounds queued frames, releases heartbeat workers across reconnects, and exposes bounded close observation for external runners.
- The recommended model path keeps Provider identity in a runner-local loopback gateway reached through one Allocation-scoped TunnelSession. Axern remains a raw TCP tunnel and does not own provider protocols, routing, budgets, or Agent sessions.

## Validation And Upgrade

The release artifacts install into source-free consumers and expose the new Run inputs and low-level Tunnel connector using only `axern_sdk` public imports. Control-plane validation rejects unsafe Secret paths and modes, invalid environment names, invalid OCI references, protected or overlapping mount targets, and overlapping image/Secret paths before node delivery.

The Helm chart uses cluster-domain-independent `service.namespace.svc` targets for internal mTLS connections. PKI SANs produced by the documented bootstrap command therefore match the actual Tunnel relay target without assuming `cluster.local`.

Upgrade Axern components and SDKs together. This release directly removes the unused `ImageMount.readonly` public Proto field and does not provide a compatibility alias.
