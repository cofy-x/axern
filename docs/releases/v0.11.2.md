# Axern v0.11.2

Axern v0.11.2 makes formal release publication safely resumable after a registry or network interruption. Existing image manifests, Helm charts, SDK packages, and GitHub Release assets are accepted only when their content matches the immutable candidate; conflicting content remains a hard failure.

Helm OCI publication now applies a bounded retry to the specific registry consistency failure where a newly uploaded manifest cannot immediately be tagged, then downloads the published chart and verifies its archive digest. This release contains the same runtime convergence fix introduced in v0.11.1; v0.11.1 was only partially published and must not be treated as a complete platform release.
