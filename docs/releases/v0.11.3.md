# Axern v0.11.3

Axern v0.11.3 restores correct non-terminal workload semantics. OCI workloads without a PTY no longer receive a synthetic `TERM`; image or caller-provided values remain unchanged, while Terminal and SSH continue to set `TERM` as part of their PTY contract.

This prevents terminal-aware programs from incorrectly entering interactive mode when their standard streams are pipes, allowing finite Runs and their root filesystem results to converge normally. The regression is tracked by issue #177.
