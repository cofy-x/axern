# Axern v0.11.3

Axern v0.11.3 restores correct non-terminal workload semantics. OCI workloads without a PTY no longer receive a synthetic `TERM`; image or caller-provided values remain unchanged, while Terminal and SSH continue to set `TERM` as part of their PTY contract.

Production and verification use Axern's in-memory OCI policy directly. External base-spec configuration and runtime sample generation are removed; conformance identifies the loaded handler configuration. This addresses the unintended terminal environment tracked in issue #177; full workload acceptance is still pending.
