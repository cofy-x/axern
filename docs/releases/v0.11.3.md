# Axern v0.11.3

Axern v0.11.3 restores correct non-terminal workload semantics. OCI workloads without a PTY no longer receive a synthetic `TERM`; image or caller-provided values remain unchanged, while Terminal and SSH continue to set `TERM` as part of their PTY contract.

The production node regenerates its base spec from Axern's OCI defaults on every start. Configured base specs are normalized before image and caller environment is merged. This addresses the unintended terminal environment tracked in issue #177; full workload acceptance is still pending.
