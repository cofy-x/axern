# Axern v0.9.1

Axern v0.9.1 fixes runtime readiness and cleanup races found while qualifying v0.9.0. Deploy matching control, gateway, node, CLI, chart, image, and SDK builds.

## Runtime Reliability

- Allocation exit monitoring now starts only after sandbox activation is ready or startup recovery has classified the authoritative runtime inventory.
- Temporary sandbox control-socket failures no longer fabricate terminal results; an unavailable exit result requires durable evidence that the runtime exited or disappeared.
- Node recovery, cancellation, and runtime removal converge without reviving or prematurely terminating an Allocation.

## Local Runtime Reliability

- CLI-managed local state records its Docker Compose project, keeping source Compose and released local-runtime operations isolated.
- DNS diagnostics wait for Allocation cleanup before deleting their temporary Namespace.
- OCI verification preserves failure diagnostics until after cleanup and validates the declared output it actually writes.
