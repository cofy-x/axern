# Axern v0.11.4

Axern v0.11.4 fixes a network isolation defect: in v0.11.3, a Run using `NetworkPolicy.deny_all()` could still receive an external HTTPS response. A fresh deny-all Allocation now has no host network interface, while an unrestricted Allocation retains normal outbound access. The fix does not change the public SDK contract.

Upgrade nodes before relying on deny-all isolation. Allocations created before the upgrade do not acquire the new network boundary retroactively; cancel and recreate any still-running affected Allocations. Declared outputs and terminal Run results remain separate from network access.
