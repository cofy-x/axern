# Axern v0.12.0

Axern v0.12.0 enables Allocation-scoped, ingress-only Tunnel sessions for fresh Runs using `NetworkPolicy.deny_all()`. A caller can reach an explicitly declared sandbox loopback port through the public SDK without granting the sandbox external DNS, HTTPS, or direct-IP egress. Tunnel revocation closes access without terminating an otherwise authorized Run; failed session setup reports a stable public reason code.

Upgrade the control plane, gateway, tunnel relay, and nodes together. Existing isolated Allocations are not reconfigured in place; create a fresh Run and Allocation to use this capability. Keep the CLI, Helm chart, platform images, and SDKs on the same release version.
