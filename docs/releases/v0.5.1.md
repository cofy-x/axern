# Axern v0.5.1

Axern v0.5.1 repairs the source-free local Quickstart introduced in v0.5.0.

## Local image loading

- `axern local image load IMAGE` streams an existing host Docker image into the
  running local node. Add `--pull` when the image is not already present.
- The transfer uses the immutable Docker image ID, validates the image platform
  against the running node image, and does not create a host-side tar file.
- The node stores imported content by OCI manifest digest. A mutable ref moves
  atomically to the new generation while existing allocations retain their old
  generation until their mount lease is released.

## Upgrade notes

The imagemgr import API and node-local import metadata are intentionally
replaced. Imported images are disposable cache data; recreate the local stack
or import images again when upgrading from v0.5.0.
