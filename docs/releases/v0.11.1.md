# Axern v0.11.1

Axern v0.11.1 fixes process convergence for signal-heavy workloads under runsc. The node runtime now uses gVisor `release-20260914.0`, which includes the upstream fix for a sentry deadlock caused by `setsid()` when a sibling process shares signal handlers.

The release also keeps runtime process identity verification fail-closed with gVisor's split sentry binaries, completes bounded process cleanup after caller cancellation, and expands the rootfs snapshot acceptance path to cover failed, cancelled, and isolated fresh Runs.

There is no public protobuf or SDK API change. CLI, control-plane, node, gateway, chart, and SDK artifacts remain versioned together and should be deployed from the same release.
